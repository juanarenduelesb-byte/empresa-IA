# Acta de reunión

`acta-reunion` · **Estado:** draft

**Cuándo se usa:** Tras una reunión entre agentes, con un socio o con un interlocutor del cliente.

## Pasos

1. Asistentes, fecha y objetivo de la reunión.
2. Acuerdos (lo que se hará), decisiones (marcadas como propuesta si las deben aprobar los socios) y desacuerdos abiertos.
3. Siguientes pasos: qué, quién, para cuándo.
4. Lo que se dijo pero no se acordó no va como acuerdo.

## Resultado

Acta de una página: Asistentes · Objetivo · Acuerdos · Decisiones propuestas · Desacuerdos · Siguientes pasos (tabla qué/quién/cuándo).

## Lista de control

- ¿Cada siguiente paso tiene responsable y fecha?
- ¿Hay decisiones presentadas como tomadas sin serlo?

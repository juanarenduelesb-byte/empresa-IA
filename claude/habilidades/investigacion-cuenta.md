# Investigación previa de una cuenta

`investigacion-cuenta` · **Estado:** draft

**Cuándo se usa:** Antes de una primera conversación.

## Pasos

1. Solo fuentes públicas: web, registros oficiales, memoria anual, notas de prensa.
2. Qué hace, tamaño, novedades, posible proceso con volumen.
3. Hipótesis de dolor y pregunta de apertura.
4. Fuente y fecha de cada dato. Nada de datos personales que no sean cargos públicos.

# Paquete trimestral para el gestor

`paquete-gestor` · **Estado:** draft

**Cuándo se usa:** Al cierre de cada trimestre y del año.

## Pasos

1. Libros de facturas emitidas y recibidas del periodo.
2. Resumen de IVA repercutido y soportado, retenciones practicadas y soportadas.
3. Operaciones relevantes del periodo (inversiones, préstamos, subvenciones).
4. Dudas fiscales concretas y numeradas.
5. Calendario de presentación confirmado con el gestor, nunca supuesto.

## Resultado

Carpeta del trimestre con resúmenes y preguntas, lista para enviar (la envía un socio).

## Lista de control

- ¿Las cifras cuadran con el cierre mensual?
- ¿Los plazos están confirmados por el gestor?

# Gobierno de procesos

**Estado:** propuesta, pendiente de aprobación de un socio. Orientativo: no es asesoría jurídica.

1. **Ficha:** todo proceso tiene ficha en `processes/catalog/` con 20 apartados, y dueño.
2. **Versiones:** una definición aprobada no se modifica; cada cambio crea una versión nueva, con migración o convivencia de instancias.
3. **Paso a producción (P34):**
   - validación automática;
   - pruebas;
   - revisión por alguien distinto del autor;
   - aprobación de un socio si el riesgo es medio o alto.
4. **Medición:** los procesos con KPI se miden; si no mejoran, se revisan (P18).
5. **Retirada:** se registra el motivo y qué lo sustituye.

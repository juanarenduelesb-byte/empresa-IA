# Política de fuentes

**Estado:** propuesta, pendiente de aprobación de un socio. Orientativo: no es asesoría jurídica.

1. **Orden de autoridad:**
   1. norma oficial (BOE, DOUE);
   2. regulador o supervisor;
   3. estándar (ISO, NIST, OWASP);
   4. documentación del fabricante;
   5. análisis de terceros;
   6. foros.
2. **Registro:** cada fuente se registra con organismo, URL, versión, fecha de consulta, autoridad, vigencia y estado.
3. **Normativa:** se cita la versión consolidada y se verifica en la fuente oficial antes de usarla con un cliente.
4. **Fuentes inferiores:** una fuente de nivel 5 o 6 no basta por sí sola para una afirmación normativa.
5. **Incertidumbre:** lo que no se pueda verificar se marca como laguna. No se rellena.

# Glosario

El glosario completo para socios está en la web: [`site/glosario.html`](../../site/glosario.html).

Términos de esta capa de conocimiento:

- **Capacidad:** una función que la organización sabe hacer (un especialista). No es un agente permanente (D-002).
- **Precedente:** un trabajo anterior documentado para reutilizarlo ([`precedents/`](../../precedents/README.md)).
- **Ficha draft, validated, approved, deprecated o disputed:** el estado del conocimiento.
- **Definición de proceso:** el JSON versionado que ejecuta el motor ([`processes/definitions/`](../../processes/definitions/README.md)).
- **Idempotencia:** repetir una operación no produce un segundo efecto.
- **RLS:** seguridad a nivel de fila en PostgreSQL, usada para separar clientes.
- **Puertas G0–G6:** puertas de cliente. **Puertas L0–L4:** puertas técnicas. No confundirlas (D-009).

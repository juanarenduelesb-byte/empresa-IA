# Biblioteca de precedentes

Antes de hacer algo, se busca aquí (protocolo [consultar el histórico](../knowledge/metodologias-transversales/consultar-historico.md)). Después de hacerlo, se guarda lo aprendido.

| Carpeta | Qué guarda |
|---|---|
| [`projects/`](projects/) | Proyectos terminados o en curso: qué se hizo y qué salió |
| [`solutions/`](solutions/) | Soluciones reutilizables |
| [`incidents/`](incidents/) | Fallos y su causa |
| [`lessons-learned/`](lessons-learned/) | Lecciones que cambian cómo trabajamos |

Plantillas: [precedente](plantilla-precedente.md) e [incidente](plantilla-incidente.md). Solo hechos con evidencia; nada de clientes reales.

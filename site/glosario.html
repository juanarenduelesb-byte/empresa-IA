11 · Glosario

Cada palabra técnica, en una frase.

Si en alguna página aparece un término que no se entiende, está aquí.

Agente
Un programa con IA que puede hacer pasos por su cuenta, como leer, buscar o usar una herramienta. Aquí siempre trabaja dentro de un proceso con límites.
API
La puerta por la que un programa habla con otro. Por ejemplo, nuestro sistema pide algo a un modelo de IA a través de su API.
AS-IS / TO-BE
Cómo se hace hoy un proceso (AS-IS) y cómo se hará después (TO-BE).
Auditoría / trazabilidad
Poder reconstruir después qué se hizo, quién, cuándo y con qué datos.
CEO digital orquestador
La pieza que recibe un encargo, lo entiende, hace un plan y reparte el trabajo. Organiza, no ejecuta.
Claude Code
Versión de Claude que trabaja directamente sobre el código de un repositorio: lo escribe, lo prueba y lo cambia.
CLAUDE.md
Archivo de texto en el repositorio con las reglas que Claude Code debe seguir siempre.
Conector MCP
Enlace que permite a Claude usar otra aplicación, como Gmail, Google Drive o GitHub.
Control de paso gate
Momento en que se decide con datos si se avanza a la siguiente fase.
Docker
Forma de empaquetar un programa para que funcione igual en cualquier ordenador o servidor.
DORA
Reglamento europeo de resiliencia digital para bancos, aseguradoras y otras entidades financieras. Afecta a sus proveedores tecnológicos.
Embeddings / pgvector
Técnica para buscar textos por su significado y no solo por sus palabras. Solo se usará si hace falta.
FastAPI
Herramienta de Python para construir la API del sistema.
Forward Deployed Engineer ingeniero desplegado
Ingeniero que trabaja junto al cliente, dentro de su día a día, para construir e integrar la solución.
GitHub / repositorio
Lugar en internet donde se guardan documentos y código con todo su historial de cambios. Nuestro repositorio se llama empresa-ia.
Habilidad skill
Receta escrita que Claude sigue para hacer una tarea siempre igual de bien, como redactar un acta.
Human-in-the-loop
Una persona revisa o aprueba antes de que la acción se ejecute.
Idempotencia
Si una acción se repite por error, el resultado es el mismo. Evita, por ejemplo, abrir dos veces el mismo expediente.
Instrucciones escondidas prompt injection
Texto dentro de un documento que intenta dar órdenes a la IA. Se defiende tratando todo lo leído como dato.
Integration Hub
La pieza que conecta nuestro sistema con los programas del cliente de forma controlada.
KPI / métrica
Número que dice si algo funciona, como el tiempo medio por siniestro.
LLM modelo de lenguaje
El tipo de IA que entiende y escribe texto, como Claude.
Markdown
Formato de texto sencillo con títulos y listas. Se lee bien tanto por personas como por la IA.
Multi-tenant / tenant
Un mismo sistema que sirve a varios clientes (tenants) sin que se mezclen sus datos.
Obsidian
Aplicación para leer y escribir notas en Markdown, enlazadas entre sí.
Piloto
Prueba real con usuarios reales en un perímetro limitado, con una métrica de éxito firmada.
PostgreSQL
Base de datos donde se guardan casos, tareas, permisos y registros.
Process Engine motor de procesos
La pieza que lleva la lista de tareas, su orden, sus estados, los reintentos y las aprobaciones.
Proyecto de Claude
Espacio de Claude con instrucciones y documentos propios, que Claude tiene en cuenta en cada conversación de ese proyecto.
RAW / WIKI / SCHEMA
Las tres capas del conocimiento: originales, fichas ordenadas y normas.
Reglamento Europeo de IA AI Act
Ley europea que clasifica los sistemas de IA por riesgo y fija obligaciones para cada nivel.
RGPD
Reglamento General de Protección de Datos.
RLS
Regla dentro de la base de datos que impide ver filas de otro cliente. Es una defensa adicional.
ROI
Retorno de la inversión: cuánto se gana o ahorra frente a lo que cuesta.
Tool Gateway
Puerta única por la que pasa cualquier herramienta que use la IA, con lista cerrada y permisos.
